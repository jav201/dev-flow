## ⚠️ This is a MIRROR — do not edit these files

> **Reading these files on Windows:** they are UTF-8. A shell that decodes with the system code page renders the box-drawing and the em dashes as mojibake — read them with an explicit UTF-8 encoding, and set `PYTHONIOENCODING=utf-8` before running the validator so its output is legible too. (Recorded from the 2026-09-18 publication test, where it cost a reader its first two commands; it is a runtime fact, not a flow change.)

**The canonical install is `~/.claude/commands/` and `~/.claude/templates/dev-flow/`**, versioned in **the canonical private repository**. That is what Claude Code actually loads; editing the copies here changes nothing at runtime and silently forks the system.

**To change a control or a phase rule:**
1. Edit the canonical file under `~/.claude/commands/` or `~/.claude/templates/dev-flow/`.
2. Commit it in `claude-config`.
3. **Regenerate** this folder — `python ~/.claude/docs/tools/devflow-validate.py --sync-bundle` —
   and commit here. Since rev15 the bundle is a **build output** derived from `FLOW-VERSION.md`'s
   table; do not copy by hand, and do not record a source commit in prose (see below).

## Mirror provenance — read it from the mechanism, not from this paragraph

**Every figure that used to live here was hand-kept, and every one of them was stale.** At rev56
this block declared `2026.07.28-rev1`, a mirror commit of `061bf93`, `12/12` files and controls
`C-1…C-45` — while the flow was at rev55 with 24 tabled files. A provenance line written by hand
beside the artifact it describes is the defect this flow has recorded more than any other, so the
figures are gone and the readers that derive them are named instead:

- **Revision and aggregate:** the header block of [`FLOW-VERSION.md`](./FLOW-VERSION.md), mirrored
  here beside the files it describes. It is regenerated by the bump procedure, never by hand.
- **Is this mirror byte-identical to canon?** `V15` answers it, pairwise and in both directions:
  `python scripts/devflow-validate.py --map`. That is the only honest answer to *"12/12"*, and it
  is computed at read time rather than asserted at write time.
- **Which commit produced it?** `git -C ~/.claude log -1 --format=%h` on the canon side. A sha
  typed into this file is one commit stale the moment it is typed — which is exactly how the
  `061bf93` line survived twenty-eight revisions.
- **The control census** lives in `FLOW-VERSION.md`'s `controls:` row, with its definition.

## Is this mirror current?

```bash
diff -rq ~/.claude/skills/dev-flow/commands ~/.claude/commands 2>/dev/null | grep -v '^Only in'
diff -rq ~/.claude/skills/dev-flow/templates ~/.claude/templates/dev-flow
```

Silence means current. Output means **re-copy from the canonical side** — never the reverse. To check the flow itself (not just the mirror) against its published revision, use the aggregate-hash command in `FLOW-VERSION.md`.
